# database-system

Oracle Academy "Database Design" dersi için Türkçe vize çalışma sitesi.

- Her ders kısa Türkçe anlatım, sınavda geçen İngilizce ifadeler ve ER diyagramlarıyla özetlenir.
- Her bölümün sonunda İngilizce bir test vardır.
- Statik bir sitedir (HTML, CSS, JS); backend yoktur. İlerleme ve test puanları tarayıcıda saklanır.

Yerelde açmak için `index.html` dosyasını tarayıcıda açman yeterli.
